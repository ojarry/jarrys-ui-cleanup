# Jarry's UI Cleanup

A lightweight client-side mod that strips the clutter out of Minecraft's menus and gives the game a darker, cleaner look. Every feature can be turned on or off.

## Menus

Removes the Realms and Feedback / Bug Report buttons from every menu, including the Realms notification dot. Removes the Advancements button from the pause menu (the L key still works) and tidies the Friends icon into that row. On the title screen, the Accessibility and Language icons are removed (both are still in Options) and the remaining small icons move to a neat row in the bottom-left corner.

## World Loading

Skips the experimental settings warning and the backup prompt when you create or open a world.

## Chat

Removes the chat report option and strips chat signatures. With Strip Chat Signatures on (the default), your chat messages and commands are sent without signatures, so they can't be reported. You can turn it off anytime.

Some servers require signed chat. With "Allow Signed Chat If Required" on (the default), your chat is signed on those servers only, and a short notice tells you. Turn it off and chat is blocked on those servers with a clear message instead, so you never get kicked.

If No Chat Reports is installed, these chat features step aside and let that mod handle it.

## Loading Screen

Replaces the red Mojang loading screen with a dark crimson background and the Jarry logo.

## Dark UI

Includes Jarry's Dark UI as a built-in resource pack. Turn it on or off anytime in the Resource Packs screen.

## Extras

Turns off telemetry, quiets tutorial and recipe toasts, disables the Ctrl+B narrator shortcut, speeds up loading, and can hide the recipe book button (off by default).

## Requirements

Client-side only. Available for Fabric and NeoForge on Minecraft 26.3 and 26.2. Fabric also needs Fabric API.
